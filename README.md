# Smart Listing AI

AI-powered multi-marketplace listing automation platform for sellers and resellers.

## Features

- AI listing generation from product photos
- Bulk listing workflow
- Marketplace API integrations
- Assisted publishing system
- Browser autofill automation
- AI pricing suggestions
- Marketplace-ready descriptions
- Seller workflow automation
- Multi-marketplace support

## Supported Platforms

- eBay
- OLX
- Allegro
- Prom.ua
- Facebook Marketplace
- Vinted
- Shopify

## Tech Stack

- Next.js
- React
- TypeScript
- FastAPI
- PostgreSQL
- OpenAI API
- Chrome Extension APIs

## Project Goal

Build a scalable AI platform that helps sellers create and publish listings faster across multiple marketplaces.
